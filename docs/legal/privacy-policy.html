1. はじめに

開発者(以下「私たち」)は、本アプリのご利用にあたり、利用者(以下「お客様」)のプライバシーを最大限に尊重します。本ポリシーは、本アプリがどのような情報を取り扱い、どのように保護するかを説明するものです。

本アプリは 完全にオフラインで動作する設計 であり、お客様のワークアウト記録その他の個人情報を 私たちのサーバーに送信したり、私たちが取得したりすることは一切ありません。

本アプリをダウンロードまたは使用することにより、お客様は本ポリシーの内容に同意したものとみなされます。本ポリシーに同意いただけない場合は、本アプリのご利用をお控えください。

2. 収集する情報 / 収集しない情報

2.1 私たちが収集しない情報

私たちは、以下の情報を 一切収集しません:

  • 氏名、メールアドレス、電話番号その他の連絡先情報
  • 生年月日、性別、住所などのプロフィール情報
  • 位置情報(GPS、Wi-Fi、Bluetooth ビーコン等を含む)
  • 連絡先、写真、カレンダー、リマインダーなど他アプリのデータ
  • カメラ、マイクからの音声・映像
  • 端末識別子(IDFA、IDFV を含む広告 ID)
  • 利用ログ、クラッシュレポート、操作履歴(アナリティクス)
  • IP アドレス、ネットワーク情報

本アプリには アカウント登録機能・ログイン機能はなく、利用者を識別する仕組みを持ちません。

2.2 端末内にのみ保存される情報

以下の情報は、お客様の 端末内(SwiftData ローカルストレージ) にのみ保存され、外部に送信されることは一切ありません:

  • 作成したワークアウトメニュー、テンプレート
  • 実施したワークアウトのセット、レップ、重量、距離、時間などの記録
  • 履歴、目標、お気に入り種目
  • アプリ内設定(単位系、テーマ、言語、通知設定など)

これらのデータは お客様自身のもの です。アプリを削除すると、これらのデータも端末から削除されます(iCloud バックアップを有効にしている場合は Apple のバックアップに含まれることがあります)。

2.3 Apple が処理する情報(私たちはアクセスできません)

本アプリは Apple のプラットフォーム上で動作するため、以下の情報は Apple が処理しますが、私たちは個別のお客様情報にアクセスできません:

データ処理元私たちのアクセス可否
App 内課金(Pro 解除)App Store / StoreKit不可(購入の事実のみアプリ内で確認)
領収書、決済情報Apple一切不可
集計レビュー、評価App Store公開ページから閲覧可能(個人特定不可)

App Store および StoreKit における Apple の取扱いについては Apple Privacy Policy をご参照ください。

3. 通知について

本アプリは、ワークアウト中の インターバルタイマー終了通知 にローカル通知(UNUserNotificationCenter)を使用します。

  • 通知は オプトイン(初回利用時にお客様の許可が必要)です
  • 通知の内容は すべて端末内で生成 され、サーバーから送信されることはありません
  • 通知の許可は iOS の「設定」アプリからいつでも取消可能です
  • プッシュ通知サービス(APNs)は使用しません

4. 端末の権限(Permissions)

本アプリが iOS に要求する権限は最小限です:

権限用途必須/任意
ローカル通知インターバルタイマー終了通知任意
Live Activitiesロック画面でのセッション進捗表示任意
Family SharingApp 内課金(Pro 解除)のファミリー共有任意

本アプリは以下の権限を 一切要求しません: HealthKit、カメラ、マイク、位置情報、連絡先、写真ライブラリ、Bluetooth、Motion(歩数等)。

5. 第三者サービス・SDK

本アプリは 一切のサードパーティ SDK を組み込んでいません:

  • Google Analytics、Firebase、Mixpanel 等の解析 SDK なし
  • Crashlytics、Sentry 等のクラッシュレポート SDK なし
  • AdMob、Meta Audience Network 等の広告 SDK なし
  • ソーシャルログイン SDK なし

本アプリが連携する第三者サービスは Apple のサービスのみです: App Store / StoreKit、Local Notifications、iCloud Backup(任意)。

6. 同梱データの帰属

本アプリには 150 種目以上のエクササイズデータと SVG イラストが同梱されています:

  • エクササイズデータ: 開発者が独自に作成、または公開ドメイン情報から編集
  • SVG イラスト: workout-cool (MIT License) より一部利用、改変

詳細は本アプリ Settings → About → 第三者ライセンス、またはリポジトリの THIRD_PARTY_NOTICES.md をご参照ください。

7. 子供のプライバシー(COPPA / 児童保護)

本アプリは年齢制限を設けていませんが、13 歳未満のお子様を対象とした機能や広告は含まれていません。私たちは 13 歳未満のお子様から個人情報を意図的に収集することはありません。13 歳未満のお子様による本アプリのご利用は、保護者の同意と監督のもとで行ってください。

万が一 13 歳未満のお子様の個人情報を取得していることが判明した場合は、即座に削除いたします。お心当たりがある場合は本ポリシー末尾の連絡先までご一報ください。

8. お客様の権利

本アプリはお客様の個人情報を収集・保有していないため、一般的なデータ主体の権利は 本アプリを端末から削除することで完結 します。

8.1 GDPR(EU 一般データ保護規則)

EU/EEA/UK にお住まいのお客様は、GDPR に基づき以下の権利を有します:

  • アクセス権 / ポータビリティ権: 本アプリで作成したデータは設定画面の「エクスポート」(Pro 機能)から CSV 形式で取得できます
  • 削除権 / 忘れられる権利: アプリを iOS の標準手順で削除すると、すべてのデータが端末から削除されます
  • 異議申立権: 私たちはお客様のデータを処理していないため、異議申立の対象となる処理活動はありません

8.2 CCPA(カリフォルニア州消費者プライバシー法)

  • 私たちはお客様の個人情報を 販売しません
  • 私たちはお客様の個人情報を 共有しません
  • 開示請求、削除請求、Opt-Out のいずれも、お客様自身がアプリを削除することで実現可能です

8.3 個人情報保護法(日本)

  • 私たちは個人情報保護法上の「個人情報」を取得していません
  • お客様の端末内データはお客様自身に帰属し、私たちは取り扱っていません
  • 個人情報保護委員会への申立先: https://www.ppc.go.jp/

8.4 その他の地域

その他の国・地域の法令に基づき同様の権利を有する場合、本アプリを端末から削除することで権利行使が完結します。追加の対応が必要な場合は本ポリシー末尾の連絡先までご連絡ください。

9. データの保持期間

私たちは個人情報を保有しないため、保持期間という概念が当てはまりません。お客様の端末内データは、お客様が削除するか、アプリをアンインストールするまで端末内に保持されます。

10. データの国際移転

私たちはお客様のデータを国外に移転しません。すべてのデータはお客様の端末内にとどまります。

App Store / StoreKit の決済処理や iCloud バックアップは Apple が世界各地のサーバーで処理する場合があります。詳しくは Apple のプライバシーポリシーをご確認ください。

11. アクセシビリティ

本アプリは以下のアクセシビリティ機能をサポートしています:

  • VoiceOver(スクリーンリーダー)
  • Dynamic Type(文字サイズ拡大)
  • Reduce Motion(視差効果の軽減)
  • High Contrast(コントラスト強調)
  • ダークモード

これらは iOS の「設定」→「アクセシビリティ」から有効にしてください。

12. セキュリティ

  • すべてのデータはお客様の端末内に保存され、ネットワーク送信は行いません(StoreKit 通信を除く)
  • お客様の端末の標準的なセキュリティ機能(パスコード、Face ID / Touch ID、ファイル保護クラス)に依存します
  • App Transport Security (ATS) を有効化(StoreKit 等の Apple 純正通信のみ TLS で暗号化)

ただし、お客様の端末を紛失したり、第三者に物理的にアクセスを許した場合のデータ流出の責任は負いかねます。端末のロック設定を有効にしてください。

13. 本ポリシーの変更

  1. 本ドキュメント末尾の「最終更新日」を更新
  2. 重大な変更がある場合は、アプリ起動時のダイアログまたはアプリ更新時のリリースノートで通知
  3. お客様が変更後の本アプリを引き続きご利用いただいた場合、改訂後のポリシーに同意したものとみなします

過去のバージョンは本リポジトリの Git 履歴から参照可能です。
